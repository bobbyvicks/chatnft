ChatNFT

A pixel editor that works on the grid your art was actually drawn on. Drop a PNG in, rebuild it at its true resolution, and edit it cell by cell — then download a clean file. Nothing is uploaded anywhere.

Layers

The top of this list is drawn in front of everything below it. Renaming a layer takes every trait on it along; removing one sends its traits to unsorted rather than deleting them. This order is what the character builder and the sheet draw in.

Build a character

Stacks one saved trait per layer, in the order the collection draws them, over a base. This is the check that the set actually works together - a trait can look right on its own and still collide with the hat above it.

Measures

Reads the repeating block size from where the art's own edges fall and suggests a resolution. You confirm it — you know what you drew at.

Recovers

Rebuilds each cell from the median of its source pixels, so no colour appears that was not already there.

Edits

Paint on the true grid with the palette taken from your own image, then download a clean PNG.

Pull a trait off a character

If someone sends you the whole character wearing a hat, a necklace, glasses, drop it here with the bare character it was drawn over. Whatever differs between the two is the trait, and it comes back on transparency ready to layer. Load a bare character for each skin once; the right one is matched automatically per submission.

From your image

Background

Floods in from the edges, so only colour connected to the border goes. A white shirt in the middle stays.

Transform

Mirrors the whole canvas, so a trait drawn for one side becomes the other without redrawing it. The canvas keeps its size, which is what keeps the trait lining up on a character.

Recolour

Pick a colour above to replace.

Swaps one colour for the current one everywhere it appears, which is how you get five versions of the same trait without redrawing it. Transparent cells are never touched.

Base layer

55%

Sits behind the trait so you can see how it lines up. It is never drawn into the artwork, so it cannot end up in a save or an export. Pick M to drag the trait over it.

Outline

1 cell

Drawn in the current colour, outside the art, never over it. Snapping rounds the silhouette to whole blocks before the outline is grown, so a ragged crop cannot leave one-cell indents in it — at the cost of detail finer than a block.

Ask Claude

Names it and picks a layer from the image. Runs on the server so no key is exposed.

Save to project

Kept in this browser under the layer you choose, so you can reopen it later or download the whole set at once.

Export

All exports are PNG with no smoothing. Keep the full canvas for anything you will layer back onto a character — that is what makes it line up. Trimmed puts the crop offset in the filename so the position is not lost.
