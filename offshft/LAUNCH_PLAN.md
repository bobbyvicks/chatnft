# Launch plan

## Phase 1: Set up (week 1). Owner tasks, about 1–2 hours total

- [ ] Search "OFF SHFT" on Instagram, TikTok, Etsy and the Canadian trademark database (CIPO). Stop and rethink if a clothing brand already uses it.
- [ ] Buy offshft.com (and offshifthats.com as a backup that forwards to it)
- [ ] Decide on the Shopify store: use the existing connected store or start a new one
- [ ] Rename the store to OFF SHFT and connect the domain
- [ ] Install Printful or Printify and connect it to Shopify
- [ ] Claim social handles: @offshft on Instagram, TikTok and Facebook (or the closest available)

## Phase 2: Build (weeks 1–2). Mostly agents

- [ ] Agents: logo and wordmark options (3 directions), owner picks one
- [ ] Agents: draft designs 1–15 from DESIGNS.md as vector files plus mockups
- [ ] Owner: approve or reject each design
- [ ] Agents: product titles, descriptions, tags and SEO for each approved hat
- [ ] Agents: store pages: home, about (the OFF SHFT story), FAQ, shipping and returns
- [ ] Owner: order samples of the top 3–5 hats and check embroidery quality

## Phase 3: Launch (week 3)

- [ ] Owner: publish products after samples pass
- [ ] Agents: launch posts (photos of samples, story of the brand), 2 weeks of content drafted ahead
- [ ] Owner: post them, tell friends, coworkers, fishing/golf/cornhole groups
- [ ] Optional: a small paid-ads test ($5–10/day for 2 weeks), owner sets the budget

## Weekly routine after launch (owner: ~1 hour/week)

| Agents do | Owner does |
|---|---|
| Report last week's visits, orders, top sellers | Read the report (5 min) |
| Propose 2–3 new designs based on what sold | Approve or reject |
| Draft next week's social posts | Post them or schedule them |
| Answer-draft any customer emails | Send replies |
| Update listings, fix anything broken | Approve anything that costs money |

## Calendar hooks (plan drops around these)

- **Victoria Day long weekend (May)**: start of cottage and fishing season
- **Father's Day (June)**: the biggest hat-gifting moment of the year
- **Canada Day (July 1)**
- **Civic holiday (August)**
- **Labour Day (September)**: "earned it" message fits perfectly
- **Black Friday / Christmas**: gifts and toques
- Fishing season openers (walleye, bass) and the start of golf season
